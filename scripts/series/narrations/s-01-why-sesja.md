Ever wonder why a Chicago Rails conference app from 2012 named its talk model Sesja?

<!-- cue:explain -->
In Ruby on Rails, Session is already reserved for HTTP session state. Instead of fighting the framework, Chicago Code Camp named the ActiveRecord model Sesja — Polish for session — and routed it publicly at slash sessions. Clean URLs for attendees, zero naming collisions in Rails 3.
